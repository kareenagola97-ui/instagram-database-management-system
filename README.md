# Instagram Database Management System

## Project Overview

This project focuses on designing and implementing an Instagram Database Management System using PostgreSQL. The project demonstrates how a real-world social media platform manages users, posts, comments, likes, followers, and hashtags.

---

## Technologies Used

- PostgreSQL
- pgAdmin4
- SQL
- ER Diagram

---

## Project Objectives

- Design a relational database schema
- Create an ER diagram
- Implement SQL tables
- Perform data analysis
- Analyze user interactions

---
